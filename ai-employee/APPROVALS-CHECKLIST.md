# ⏸️ APPROVALS CHECKLIST — One-Pager for Reviewing Drafts Before Sending

*Print this. Tape it next to your screen. Use it every time you tick a box in `daily/approvals.md`.*

---

## 🛡️ The 7 Checks Before You Tick ☐ → ☑

For each draft, work through these in order. If **any check fails**, don't send — fix it first.

### ✅ 1. Source verified — Rule 2
- [ ] Every name, company, deal value, spec, price in the draft is **from real data** (email thread, PROSPECTS.md, PRODUCTS.md, daily/research.md)
- [ ] **No invented numbers** — if a spec was a placeholder, you've now replaced it from `PRODUCTS.md`
- [ ] **No invented facts** — if a research claim appears, you can point to the cited source

### ✅ 2. Recipient verified — "is this person real and current?"
- [ ] **LinkedIn check** — name appears in current role at the named company
- [ ] **Public source** — the person's role + company is verifiable in press / annual report
- [ ] **Routing confirmed** — you picked the right desk (e.g., cobalt trader, not cathode refiner; procurement, not legal)
- [ ] If unsure: route via general inbox or contact form, *not* a guessed personal email

### ✅ 3. Voice match — sounds like me, not a bot
- [ ] Subject line: short, direct, no "I hope this email finds you well"
- [ ] Opening: "Hi [Name]," — not "Dear Sir/Madam"
- [ ] Body: ≤ 5 short paragraphs, bullets where useful, "Best, Hendrixx"
- [ ] **No AI tells** — no "moreover", "furthermore", "I'd be delighted", "synergies", "circle back"
- [ ] Length fits the ask — RFQ responses longer, cold outreach shorter

### ✅ 4. Ask is clear — one specific thing they can say yes/no to
- [ ] Single ask (one meeting, one sample, one document) — not "let's explore opportunities"
- [ ] **Two specific questions** that move the conversation forward (used in most drafts)
- [ ] Concrete time window suggested (Tue/Thu EAT, next week) — not "whenever you're free"
- [ ] Signature has all fields filled: name, role, direct line, website — no `[+ add yours]` placeholders

### ✅ 5. Timing is honest — are you actually ready for what you're pitching?
- [ ] If draft says **"shovel-ready with signed offtake"**: do you have signed offtake? If not, soften
- [ ] If draft says **"we supply [X] volume"**: does PRODUCTS.md back that up?
- [ ] If draft says **"deck / assays / samples ready to send"**: do they exist? Otherwise say "preliminary"
- [ ] If draft implies a relationship (PIF/Ma'aden JV, PIC mandate): is the public source verifiable?

### ✅ 6. Security — nothing dangerous in the send
- [ ] **No real credentials, API keys, or tokens** in the email body
- [ ] No confidential client names, deal terms, or financial details you wouldn't want forwarded
- [ ] No attachments referenced that contain sensitive data
- [ ] **Sender identity verified** — you're sending from the right account, not a misconfigured alias

### ✅ 7. Permission — you're sending in Hendrixx's voice, not your own
- [ ] Sender: the Hendrixx-ai business email (or alias) — not personal
- [ ] You are authorised to make outreach on behalf of the business
- [ ] If the ask is *significant* (contract, equity deal, payment): a human has reviewed
- [ ] If unsure: defer, add to `daily/approvals.md`, and ask Hendrixx (me) before sending

## 🚦 Decision Matrix

| All 7 checks pass | Action |
|-------------------|--------|
| ✅ | Tick the box in `daily/approvals.md`, send from your Gmail, log the sent time |
| 5–6 pass, 1–2 yellow | Flag the issue in `daily/approvals.md` notes; fix before ticking |
| ≤ 4 pass | **Do not send.** Update the draft, re-check, return to it tomorrow |

---

## 📝 After-Send Checklist

- [ ] Tick the box in `daily/approvals.md` (move from "Awaiting" to "Approved & Done log")
- [ ] Note: who, when sent, what account, subject line
- [ ] Set a reminder for **5 business days** if no reply (manual or `daily/follow-up.md`)
- [ ] If reply arrives: add to `PROSPECTS.md` with new stage, new next step

---

## 🧯 Rollback (if you sent the wrong thing)

1. **Recalling sent mail** is unreliable — Gmail does not delete on recall for external recipients
2. **Best practice:** if it's an external mistake, follow up with a short correction email *immediately* (best practice per [FIRST.org](https://www.first.org)): *"Hi [Name] — quick correction on the email I just sent: [one-line fix]. Apologies for any confusion."*
3. **Internal mistake:** delete the thread locally, update `daily/approvals.md` notes
4. **Repeat the 7 checks** before any future send
